# SNHZ_navigate

神农慧种系列智能体门户网站。深蓝品牌框架、浅色工作区与农业绿操作按钮，与慧种稻工作台共用视觉方向。

## 本地预览

无需安装依赖或构建。仓库根目录运行 `python3 -m http.server 5221 --bind 127.0.0.1`，访问 `http://localhost:5221/`（远程开发需转发端口）。共享主机请使用本人分配的端口。

根入口 `index.html` 跳转到 `html/index.html`；原有 `/html/index.html` 访问路径保持兼容。部署时发布整个仓库静态目录，保留 `html/`、`css/`、`js/`、`assets/` 的相对路径。

## 接入与交互

- 当前展示七个产品入口；慧种稻、慧感知、慧耕耘沿用现有 `.agent-link` 地址，慧种麦、慧种植、慧表型、慧育种在正式地址接入前显示“即将开放”。
- 顶部以智能体服务为主入口，并通过“研究中心、科研成果、动态资讯、资源服务、合作交流”接入国家信息农业工程技术中心内容；所有站外链接均在新窗口打开。
- 首页“科研能力融入智能服务”专区展示四大研究方向，并保持与智能体中心一致的深蓝、农业绿品牌视觉。
- 支持关键词搜索、场景筛选、无结果重置、键盘焦点和手机单列布局。
- 最近访问只记录当前浏览器真实点击的智能体与时间，支持清空；不读取各业务系统的账号、会话或任务。浏览器禁用存储仍可使用导航。
- 没有 JavaScript 时，七张卡片与三个已接入服务链接仍可查看和访问。
- 尚未接入的产品不生成虚假跳转，正式入口明确后再替换“即将开放”状态。
